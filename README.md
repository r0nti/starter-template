# Starter Template

A production-ready starter template for frontend projects.

## Getting Started

### 1. Clone the repository
```bash
git clone git@github.com:r0nti/starter-template.git
cd starter-template
```

### 2. Set Node.js version
This project requires Node.js v12.0.0. If you use [nvm](https://github.com), run:
```bash
nvm use 12.0.0
```

### 3. Install dependencies
```bash
npm install
```

### 4. Available Scripts

#### Development
To start the project with hot-reload:
```bash
npm run start
```

#### Production
To build the project for production:
```bash
npm run build
```
